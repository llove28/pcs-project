# Items we already have

PCS has a number of photographs. We will need to label and organize these files, then use the Curation Guidelines to determine what will be added to the official collection.

1. Sort items by season and event into appropriate folders
    - When creating new folders, use the following naming format:
        - PCS_[Season Year] > PCS_[Season Year]_[Event]
2. Identify the subject of the photos, and use this information to rename the files using the File Naming System
3. Identify items for official collection using the Curation Guidelines
4. Use the Contributor Form to record metadata for official collection items

# New items

PCS members and supporters will be invited to contribute items to the collection. Follow these steps to guide contributors through this process and ensure metadata is properly collected.

1. When possible, conduct a pre-interview (using the Curation Guidelines) to verify that the items they want to contribute fit our needs. This will help us keep a handle on storage/workload.

2. Have all contributors sign the Contributor Agreement, granting us permission to publish their items in the collection.

3. Collecting items
    - Digital items
        - When possible, have contributor submit items via Contributor Form to ensure metadata is recorded
            - Otherwise, cataloger should request this info from contributor and use Contributor Form to record metadata
    - Rename files using File Naming System
    - Place the files in the corresponding Collection folder  

<br></br>
4. Physical items
    - When accepting physical items:
        - Label a folder with the contributor’s name to keep the items secure and avoid mix-ups
        - Gather metadata from contributor about the items (use Metadata Checklist printout)
        - Let contributors know the items will be returned once they’ve been digitized
    - Make sure all the items fit the Curation Guidelines
    - Let Leesa know and/or set up a time to get the items digitized at U of I Library
    - Once digitized:
        - Name the files using the File Naming System
        - Use the Contributor Form to record the information from the Metadata Checklist  
        - Move the file to the corresponding Collection folder
